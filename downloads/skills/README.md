# Moon Cortex · Agent Skills

Each ZIP is an optional Agent Skill containing its own `SKILL.md` and a complete module snapshot. Choose the skill from the corresponding [module page](../../README.md#choose-a-module). Installation depends on support in the receiving AI environment. These packages do not themselves provide an image renderer, account access, ongoing storage or professional authority.

The live module entry remains the semantic authority. In bundled Markdown, links outside the module are redirected to the canonical GitHub paths; methods and module-internal links remain intact. Rebuild with `python scripts/build_skill_packages.py`; verify exact correspondence with `python scripts/build_skill_packages.py --check`. Documentation is CC BY 4.0 and included code is Apache 2.0; each archive contains attribution, notice and both license texts. The existing module ZIPs in `downloads/` remain available as separate documentation packages.
