# Probability Calibration System Changelog

## 0.1.0-pre.1 — 2026-09-30

Initial public pre-release.

- established one canonical entry and a complete module package;
- generalized a field-first calibration method while keeping private source state and local context outside the package;
- made qualitative bands first-class and restricted numerical precision to defensible evidence;
- separated fit, evidence, probability, and confidence in the estimate;
- added source freshness, update triggers, synthetic examples, reality tests, and high-stakes boundaries;
- made Moon Source an optional context-governance bridge, not a permanent runtime dependency.
