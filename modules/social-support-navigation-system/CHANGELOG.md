# Social Support Navigation System Changelog

## 0.1.0-pre.1 — 2026-09-04

Initial public projection of a bounded social-support navigation system.

- generalized reusable architecture from the private internal donor project **Defensoria Social**;
- adopted **Social Support Navigation System** as the public identity to avoid confusion with public or regulated authorities;
- separated surface problem, function, dependency, barrier, passage, first useful door, owner and event checkpoint;
- added Living Case State guidance without exporting live case state;
- added current-resource, jurisdiction and official-source contracts;
- added Support Handoff, privacy, claim-ceiling and legal/clinical/regulated-professional boundaries;
- added synthetic reality tests and newly composed fictional examples;
- added the module-specific portable at `downloads/social-support-navigation-system.zip`.

This public pre-release does not establish social-work efficacy, clinical or legal validity, eligibility authority, institutional adoption, measured outcomes or production readiness.
