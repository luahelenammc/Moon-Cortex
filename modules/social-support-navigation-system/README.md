# 🧭 Social Support Navigation System

**Turn a fragmented support situation into a smaller, safer route through needs, barriers, institutions, owners and bounded next steps.**

[📖 Read the module](README.md) · [▶️ Start / canonical entry](SOCIAL_SUPPORT_NAVIGATOR.md#first-use) · [⬇️ Download complete package](../../downloads/social-support-navigation-system.zip) · [🌙 Moon Cortex](../../README.md)

## Use this when

- support is scattered across relatives, services, institutions or informal dependencies;
- the immediate problem is unclear because several barriers overlap;
- you need a first useful institutional door rather than an unranked directory;
- a situation may need a Living Case State, Resource Pack or bounded Support Handoff.

## What this module is

Social Support Navigation System is a composite Moon Cortex domain module for organizing passage through fragmented support systems. Its canonical entry, **Social Support Navigator**, reconstructs the relevant function, barriers, dependencies, support tracks, owners and checkpoints before choosing a bounded next step.

## Current-resource and jurisdiction caveat

Real services, eligibility rules, legal routes, vacancies and institutional contacts can change by place and time. When a live route matters, current official or qualified sources must verify it. A static example, old search result or package document is not a current-resource guarantee.

## Professional boundary

This module is not a government office, social-work service, clinical assessor, emergency dispatcher, law practice or eligibility authority. It can organize a support passage and clarify ownership; it cannot make regulated or institutional decisions on someone else's behalf.

## Local sovereignty

Any Living Case State, Resource Pack or handoff produced from the module belongs to the person, household, helper or authorized local system. The public package contains no live private case state and should not become the sole place where a person's current support history can be resumed.
