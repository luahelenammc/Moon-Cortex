# Moon Source Context Bridge

This is an optional bridge between the public Moon Cortex module and the public Moon Source context/method body. It is not a dependency and it does not import private Local Moon Source material.

## Ownership and jurisdiction

- **Moon Cortex** owns the identity and public contract of the Social Support Navigation System.
- **The Social Support Navigation System** owns the public social-navigation method, boundaries and module-local contracts.
- **Moon Source** may assist with installation, source authority, context governance, freshness, readback and persistent-source design when deliberately available.
- **A user or household’s local case state** remains locally sovereign.
- **Qualified institutions and professionals** retain decisions in their domains.

The short contract is:

> **Cortex by identity. Moon Source by installation and context governance. The user by final sovereignty.**

## Optional use

When the current public Moon Source is deliberately available, an installer or AI may consult only the methods needed to:

- establish source and authority boundaries;
- select a proportional local form;
- preserve source pointers and freshness;
- create a resumable local state;
- read back the result and detect stale or competing active states.

The bridge does not require routine Moon Source retrieval after a local case system is established. The Social Support Navigation System remains usable without Moon Source and must not claim to have read it when it has not.

## Privacy and non-contamination

No private Local Moon Source corpus, private case, personal runtime, hidden prompt, protected heuristic or live resource pack is required or exported by this bridge. Public Moon Source consultation does not authorize disclosure of private case material, nor does it make Moon Source the owner of the case.

The public module may receive generalized improvements that survive privacy, provenance, claim, utility and reconstructibility review. Live case facts and local institutional contacts remain in the local case/source system.

## Installation contract

If the bridge is used, the installation process should:

1. identify the user’s goal and local sources;
2. read only relevant public context methods;
3. preserve existing source truth and stable identifiers;
4. materialize the smallest useful local case or support form;
5. read back the result;
6. state what was and was not consulted;
7. leave the local system able to continue without hidden upstream memory.

The complete Social Support Navigation System ZIP is the public module portable. A Moon Source bridge is an optional installation aid, not a second package requirement.

## Boundary test

The bridge is healthy when it reduces retelling, source loss and duplicated setup while increasing the user’s ability to recover, inspect and continue their own case. If it makes the assisting AI the only custodian of the route, it has crossed from support into takeover and must be corrected.
