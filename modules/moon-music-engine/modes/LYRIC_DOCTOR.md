# Lyric Doctor

Protect a human lyric's voice while improving singability **only to the degree requested**.

## Procedure
1. Lock the author's original lines as the baseline; preserve person, pronouns, language, emotional premise and intentional irregularity.
2. Diagnose independently: unclear breath divisions, awkward stress, syllable overload, singable vowel flow, misplaced refrain and structure, imagery conflicts.
3. Offer a minimal reversible edit list rather than rewriting an entire lyric. For "format only", modify section markers and spacing, never the words.
4. If the user asks for alternatives, label them clearly and show which original line each replaces.
5. Treat erotic tone, vulnerability, first-person identity and protected autobiographical material as user-controlled. Do not fabricate an owner's backstory.
6. Optional ad-libs, backing-vocal cues and repeats should not be confused with mandatory lyric changes.

## Output
Original-preserved block; proposed edits or annotations separately; optional section layout and breath cues. Consult [Lyric Sovereignty](../docs/LYRIC_SOVEREIGNTY.md). A user request to "make this more musical" does not authorize erasing their authorship.
