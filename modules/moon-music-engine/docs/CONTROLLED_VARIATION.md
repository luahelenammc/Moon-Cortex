# Controlled Variation

Explore genuinely different sonic directions while preserving the creator's non-negotiable content.

## Intensity parameter
A percentage here is a **creative exploration control**, not a measured acoustic distance, statistical probability, or guarantee about what a generative platform will produce.

| Requested intensity | Typical changes |
|---|---|
| 0% | no voluntary change from the chosen direction |
| 5–15% | small secondary timbre, groove or mix adjustments |
| 20–35% | complementary subgenre, instrumental colors, intro/outro or chorus lift |
| 40–60% | substantial rhythmic, section or arrangement alternatives |
| 65–80% | adventurous cross-genre palette, production and structural shifts |
| 85–100% | broad sonic experimentation, still bounded by all declared invariants |

**Default when user explicitly asks for variation without a value:** 30%. Suggested mode defaults: Style Architect 25%, Lyric Doctor 5%, Song Prototyper 35%, Generator Debugger 10%. These are editorial settings, not observed optimal values.

## Mutation hierarchy

**High freedom:** genre/subgenre blend, rhythmic palette, tempo range, instrumentation, sonic texture, production space, intro/outro, bridge, layering and effects.

**Limited freedom:** section order, hook placement, titles, secondary lyrical images or framing, only if the user has not locked them.

**Protected:** original lyrics without edit permission, speaker identity, requested language, voice constraints, emotional/narrative premise, "instrumental only", prohibited traits, copyright/consent boundaries and explicit negative guidance.

High intensity, including 90%, means extensive **sonic** freedom, never 90% random rewriting of a protected lyric. If the person authorizes taste-informed exploration, a Bridge/Edge/Rift may deliberately cross or challenge their known constellations. An inferred taste feature is **not** an immutable creative constraint.

## Seeds and reproducibility

A user-provided seed can organize variation selections **only where the executing tool has a real seeded algorithm**. A text-only model claiming a seed is "true random" or that the same prompt guarantees the same Suno waveform is incorrect. Without an implemented seed, present alternatives as curated variations and label them as non-reproducible.

## Example

A user-supplied intimate piano ballad at 80% may become a sparse trip-hop / chamber-pop hybrid with rim percussion and analog synth textures while keeping every lyric word and the requested vocal identity. If the prompt ceases to serve the emotional premise, reject the candidate and generate another sound direction.

The selected intensity is optional metadata in the output, not a user burden on every run.
