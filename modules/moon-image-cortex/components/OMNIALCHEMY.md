# Omnialchemy

**System:** Moon Image Cortex · **Type:** conditional cross-cutting component
**Parent authority:** [Visual Director](../VISUAL_DIRECTOR.md#first-use) · [Component index](../docs/COMPONENT_INDEX.md)

This file is a subordinate component, **not** another general entry, personal memory, or renderer. Use it only when the task earns it. Public documentation does not install tools or persist identity data.

## Trigger and first use

Activate for a fragmentary idea, dream, emotion, memory, abstract concept or hybrid prompt that lacks visual grammar. First reconstruct the user intent and source roles; ask only for a missing detail that changes the result.

## Input → visual state

Accept text, desired atmosphere, authorized style references, subject, symbolic intent, output format and protected details. Keep unknowns explicit. Map into: semantic nucleus; emotional atmosphere; aesthetic family; materiality; composition; light; color; texture; temporal context; symbolic density; negative guidance; and renderer notes.

## Compilation algorithm

1. Recover the **meaning** without converting every abstract relationship into labels and glowing networks.
2. Choose an aesthetic family from the content and intended audience, **before** choosing motifs, palette or prompt prose. The method is stable; the appearance is not.
3. Establish a visual thesis in one sentence; choose a scene, object, portrait, editorial treatment or other actual medium.
4. Compose a plausible spatial hierarchy; select palette, time, materiality, light, focal region and negative space.
5. Translate symbolism into concrete physical decisions, only as strongly as the user's concept warrants.
6. Compile one clean instruction and a short QA plan. For materially different variants change family, composition or medium, not random adjectives.

## Anti-house-style gate

Do not default to cosmic darkness, lunar symbolism, golden ornaments, grimoires, glowing nodes, abstract maps or infographic panels. If comparable recent user-authorized outputs are **actually available**, test repetition in palette, composition, material, scale, period and symbolic grammar. Correct unjustified similarity by changing several relevant axes. Never hallucinate access to prior images.

## Outputs and QA

Produce a compact `visual_state`, `direction_sheet` and conditional renderer prompt. Inspect coherence, specificity, legibility, reference originality and whether the user's intention survives. No claim of rendering absent a returned image.

## Synthetic activation

Input: “A quiet feeling of reunion, illustrated for a public library campaign.” Output: an ordinary sunlit table with two returned books and an empty chair, rather than a magical city-map of human connection.
