# Reference Abstraction Guardrail · Anti-Echo

**System:** Moon Image Cortex · **Type:** conditional cross-cutting component
**Parent authority:** [Visual Director](../../VISUAL_DIRECTOR.md#first-use) · [Component index](../../docs/COMPONENT_INDEX.md)

This file is a subordinate component, **not** another general entry, personal memory, or renderer. Use it only when the task earns it. Public documentation does not install tools or persist identity data.

## Trigger and first use

Apply when the user supplies a reference for **style**, palette, mood, material or visual direction, especially a multi-image reference corpus. A reference supplied for styling does not authorize copying its subject, layout, recognizable characters, logo, signature, source prompt or protected graphic material.

## Extraction and structural forgetting

1. Label each source role: style, composition, factual content, edit target or authorized identity.
2. Extract abstract invariants: chromatic orchestration, contrast, light, atmosphere, focal falloff, detail density, tactile surface, scale range and genre/period constraints.
3. Do not smuggle source scenes, architectural particulars, recognizable motifs or distinctive layouts into the output specification.
4. Build a **new** subject, setting and composition. For a multi-reference style exercise, the heuristic to change three of environment, composition, motif, scale and lighting can help; it is **not** proof of legal originality.
5. Compare with reference only if actual images are available, and inspect accidental echoes. Rewrite the scene concept if it is too close.

## Output and QA

Return a `transferable_invariants` list, `excluded_specifics`, new visual thesis, final instruction and unresolved rights questions. Never pretend to have inspected absent reference files or guaranteed copyright clearance.

## Synthetic activation

Given an authorized palette study of rain-soaked neon imagery, apply the light-color relationship to a newly imagined greenhouse workbench without reproducing the source street, silhouettes or camera angle.
