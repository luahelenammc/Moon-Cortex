## Trigger and first use

Use when the user requests an aesthetic exploration, period interface grammar, moodboard, visual variation or a system of compositional parameters, rather than a single predetermined scene. ## Parameter dimensions

Represent the request as a constrained combination of: era, medium/support, surface/interface, palette, typographic grammar, density, composition, luminance, texture, noise, nostalgia, uncanny intensity, materiality, capture method and user-specified motif exclusions. Let each dimension serve content and use, rather than stacking fashionable style labels.

## Variation contract

1. Pin user-given constraints and evidence.
2. Define a viable choice pool for every free dimension.
3. Choose combinations that are historically, materially and visually coherent.
4. If randomization is requested, disclose whether a genuine random source and reproducible seed are available. Do **not** call a deterministic language-model selection “true random.”
5. Keep the first sampled output intact unless the user asks for editorial selection. Do not secretly reorder draws to favor prettier outcomes.
6. Delegate final synthesis to Omnialchemy or a specific specialist; preserve the sampled constraints.

## Output and QA
