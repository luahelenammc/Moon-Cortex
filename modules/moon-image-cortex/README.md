# Moon Image Cortex

**Visual Intelligence & Image Direction System**

Reconstruct what an image needs to do, choose a fitting visual route, compile a direction, and inspect the result against the brief. The module works with image creation, image editing, aesthetic research, consensual identity references, and visual QA.

- **Status:** Public pre-release
- **Version:** 0.1.0-pre.1
- **Canonical entry:** [Visual Director](VISUAL_DIRECTOR.md#first-use)
- **Transport surface:** [Complete module package](../../downloads/moon-image-cortex.zip)
- **License:** CC BY 4.0 documentation

## Start here

Open the [Visual Director](VISUAL_DIRECTOR.md#first-use) and describe the visual task in ordinary language. Share a reference only for the role you want it to play: style, composition, subject identity, or an edit target. If an image renderer is available, the Director can prepare a prompt or edit instruction and then inspect the actual result. Without one, it returns a usable direction and marks the image as not rendered.

## Limits

The module directs visual work; it does not install a renderer, create an image by itself, establish that a likeness is exact, or claim performance across image models. Synthetic cases test route selection and instruction consistency only. Real image fidelity requires a rendered artifact and direct visual inspection.

A profile is optional, consent-based, and user-owned. Public packages do not contain personal photos, identity canon, private reference collections, or source donor documents. See [public boundaries](../../PUBLIC_BOUNDARY.md) and [licensing](../../LICENSING.md).
