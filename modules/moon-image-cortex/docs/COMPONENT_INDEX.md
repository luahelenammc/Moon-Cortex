# Moon Image Cortex · Component map

**Most generally useful routes come first.** Choose by what the user wants to accomplish; this index is a human navigation surface, not an automatic priority ranking. The [Visual Director](../VISUAL_DIRECTOR.md#first-use) remains the **sole general operational authority**.

## Most common starting points

| Need | Component | Type |
|---|---|---|
| Turn a vague idea into coherent imagery | [Omnialchemy](../components/creative-direction/OMNIALCHEMY.md) | Shared creative direction |
| Edit only what was requested | [Conservative Photo Edit](../components/image-editing/CONSERVATIVE_PHOTO_EDIT.md) | Shared image editing |
| Produce a plausible photographic look | [Analogic Photo](../engines/photography/ANALOGIC_PHOTO.md) | Photography engine |
| Make a candid, everyday photograph | [Vernacular Snapshot Realism](../engines/photography/VERNACULAR_SNAPSHOT_REALISM.md) | Photography engine |
| Recreate an informal period snapshot, country-neutral | [Contextual Nostalgic Camera](../engines/photography/CONTEXTUAL_NOSTALGIC_CAMERA.md) | Photography engine |
| Explore an aesthetic, medium or variation | [Web Aesthetics](../components/creative-direction/WEB_AESTHETICS.md) | Shared creative direction |

For any route, [Visual QA and repair](VISUAL_QA_AND_REPAIR.md) is available as a cross-cutting inspection method.

## Experimental routes

[Pixel-World Camera Translation](../engines/experimental/PIXEL_WORLD_CAMERA_TRANSLATION.md) is **experimental**: it translates an authorized pixel-world scene into an independent physical interpretation. No broad performance claim or third-party asset permission is implied.

## Optional geographic overlays

Use geographic context only when the user requests it or trustworthy source evidence establishes the scene setting. **No nationality, country or historical period is chosen by default.** These are *not* independent primary routes.

[Geographic camera context registry](../engines/photography/regions/README.md) · [Any place, custom context](../engines/photography/regions/CUSTOM_CONTEXT.md)

Available examples: [Brazil](../engines/photography/regions/BRAZIL.md), [United States](../engines/photography/regions/UNITED_STATES.md), [United Kingdom](../engines/photography/regions/UNITED_KINGDOM.md), [Japan](../engines/photography/regions/JAPAN.md), [India](../engines/photography/regions/INDIA.md), [Mexico](../engines/photography/regions/MEXICO.md), [France](../engines/photography/regions/FRANCE.md), [Germany](../engines/photography/regions/GERMANY.md).

## Activation and authority

1. The Visual Director classifies the task, intended output, references and permissions.
2. It selects the **best-fitting** method, not the first item in this index. Popularity determines documentation placement, never semantic priority.
3. Load only the specific cross-cutting tools and specialist contract(s) needed for that request.
4. Regional context is optional and never inferred from a person's appearance, ethnicity or language.
5. Render only with an authorized, available tool; otherwise label any prompt **not rendered**.
6. Inspect actual output with [Visual QA](VISUAL_QA_AND_REPAIR.md); keep state user-owned.

## Public boundary

No private identity profiles, donor photographs, source reference packs or protected assets are included. [Public boundary](../../../PUBLIC_BOUNDARY.md) applies. Cat Canon Forge, Original Game Concept Art Engine and Cartoon Identity / Fantasy Image Set remain outside the public body pending supported generalizable source methods.
