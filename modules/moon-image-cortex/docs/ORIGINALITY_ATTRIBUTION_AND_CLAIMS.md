# Originality, attribution and claims

## Reference use

First ask what a reference is for. An image can be an edit target, identity reference, composition reference, factual source, or aesthetic reference. A single file may have multiple roles, each with a separate boundary.

For aesthetic references, transfer only properties the user requested: for example material, palette, era, contrast, pacing, or spatial density. Build a new subject, setting, composition and wording. The Anti-Echo heuristic asks a multi-reference direction to move at least three of five axes—environment, composition, motif, scale and light—where relevant. It is an originality practice, not a legal safe harbor.

Do not reproduce protected logos, branded interfaces, distinctive characters, artist signatures, campaign layouts, source prompts, exact slogans, lyrics, or third-party photographs without an appropriate authorization and a task that requires them. Prefer fictional names and newly designed marks.

## Public artistic references

Some historical design ideas are discussed alongside external public references. These references are **credits for identifiable influences**, not source images or ready-to-copy templates:

- **Lived-In Retrofuturism:** counterfactual period advertising and historical visual perspective, including the public [xdEArx Reddit example](https://www.reddit.com/r/ChatGPT/comments/1uvgq69/i_asked_chatgpt_to_imagine_what_modern_brands/). The engine instead produces original visual composition and scene logic.
- **Vintage Editorial Rubber Hose Poster:** readable editorial metaphors and humane representation. [Jade Bern's public portfolio](https://hug.art/artists/jadebern/about) and [Instagram](https://www.instagram.com/jade.bern/?hl=en) are credited as artistic references, **not** as permission to imitate the artist, copy protected work, or imply endorsement.

## Tool-neutral aesthetic methods

Chromatic Dream Logic coordinates palette, materials, light and visual hierarchy. It is a direction method, not a promise of identical results across generators or a model-specific preset.

## Evidence ladder

Keep the following claims separate:

- **Protocol specified:** documents define route and boundaries.
- **Textually checked:** synthetic fixture exercises route selection or instructions.
- **Prompt prepared:** a prompt or edit direction exists; nothing has necessarily been rendered.
- **Rendered:** a named tool returned an image in the task.
- **Inspected:** the actual image was opened and compared with the brief.
- **Measured:** a defined metric and evaluation set support a claim.
- **Externally adopted:** evidence shows another person or organization used the module.

This release includes public documentation, synthetic textual fixtures, and a reproducible documentation ZIP. It does not claim image-model validation, exact likeness, artistic performance, comparative renderer quality, user adoption, or external adoption.
