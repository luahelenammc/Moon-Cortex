# Originality, attribution and claims

## Reference use

First ask what a reference is for. An image can be an edit target, identity reference, composition reference, factual source, or aesthetic reference. A single file may have multiple roles, each with a separate boundary.

For aesthetic references, transfer only properties the user requested: for example material, palette, era, contrast, pacing, or spatial density. Build a new subject, setting, composition and wording. The Anti-Echo heuristic asks a multi-reference direction to move at least three of five axes—environment, composition, motif, scale and light—where relevant. It is an originality practice, not a legal safe harbor.

Do not reproduce protected logos, branded interfaces, distinctive characters, artist signatures, campaign layouts, source prompts, exact slogans, lyrics, or third-party photographs without an appropriate authorization and a task that requires them. Prefer fictional names and newly designed marks.

## Recorded source lineage

The private donor records two useful lineages. This public module retains the general design principles while excluding the source assets and source prompts.

- **Retrofuturo Habitável:** the donor records inspiration from a public Reddit post by xdEArx, “I asked ChatGPT to imagine what modern brands would look like in 1970s ads” ([post](https://www.reddit.com/r/ChatGPT/comments/1uvgq69/i_asked_chatgpt_to_imagine_what_modern_brands/)). The transferable method is counterfactual historical perspective, editorial systems, a believable relation between infrastructure and lived world, and period print logic. No brand advertisement, prompt, character, slogan, logo, source layout, or exact composition is included. This lineage note is attribution, not a claim of collaboration or permission.
- **Vintage Editorial Rubber Hose Poster:** the donor records an artistic influence associated with [Jade Bern’s public Instagram](https://www.instagram.com/jade.bern/?hl=en) and [portfolio](https://hug.art/artists/jadebern/about). The published route is reduced to general editorial principles: one conflict, one visible mechanism, a clear visual turn, readable type and humane representation. It does not instruct a renderer to imitate Jade Bern, include her work, or imply collaboration, endorsement or license.

A lineage reference documents where a method came from. It is not permission to copy an asset or to imitate a living artist. The route remains subject- and task-led.

## Historical tool reference

Chromatic Dream Logic is a meta-style compiler documented in the donor’s historical Midjourney V3 context. The public route carries no API, model, weights, preset, or equivalent-performance claim. Its palette, material, light and focal hierarchy can be directed independently of that historical service.

## Evidence ladder

Keep the following claims separate:

- **Protocol specified:** documents define route and boundaries.
- **Textually checked:** synthetic fixture exercises route selection or instructions.
- **Prompt prepared:** a prompt or edit direction exists; nothing has necessarily been rendered.
- **Rendered:** a named tool returned an image in the task.
- **Inspected:** the actual image was opened and compared with the brief.
- **Measured:** a defined metric and evaluation set support a claim.
- **Externally adopted:** evidence shows another person or organization used the module.

This release includes public documentation, synthetic textual fixtures, and a reproducible documentation ZIP. It does not claim image-model validation, exact likeness, artistic performance, comparative renderer quality, user adoption, or external adoption.
