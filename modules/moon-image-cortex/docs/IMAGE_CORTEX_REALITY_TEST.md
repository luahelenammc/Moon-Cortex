# Moon Image Cortex reality test

These twenty-two text-only fixtures exercise route selection, boundaries, and claims. They are not image files and do not measure renderer fidelity.

| Test intent | Expected route | Acceptance check |
|---|---|---|
| Fragmentary abstract concept | Omnialchemy | Choose a concrete scene, medium and light; do not default to a cosmic dashboard. |
| Contemporary documentary photo | Analogic Photo or documentary direction | Natural lens and light; no unsolicited surrealism. |
| Brazilian 1990s family album | Nostalgic Camera BR 90s + Vernacular Snapshot Realism | Plausible region and capture ecology; US props are not the default. |
| US 2000s disposable camera | Vernacular contextual variant | Reconstruct US 2000s capture ecology; no Brazilian-context leakage. |
| 2000s XP web portal | Web Retro Image Gen | Period interface grammar; no modern SaaS UI or copied brand. |
| Aqua-era fictional app icon | Aqua-Skeuo Icon Forge | Tactile, legible original icon; no copied trademark. |
| 1970s future city poster | Retrofuturo Habitável | Historical ontology, original setting and print grammar, representation QA. |
| Non-gothic chromatic image | Chromatic Dream Logic | Color, material and composition logic without prescribed theme. |
| Late Y2K uncanny bedroom | Sentimental Uncanny | Warmth plus subtle unease; not horror by default. |
| Vertical atmospheric lyric-style still | Sublime Lyric Still | One visual force, small subject, sparse original wording. |
| Vintage advocacy poster | Vintage Editorial Rubber Hose Poster | Legible thesis, original figure, seriousness gate. |
| Game screenshot to embodied scene | Pixel-World Camera Translation, experimental | No copied sprites/logos or official affiliation; retain experimental label. |
| Consenting subject identity profile | Human Canon Forge | Subject authority; separate observed details from unknowns; controlled variation. |
| Real subject without reference | Human Canon gap statement | Do not claim identity preservation without usable evidence. |
| Reference image requests style-only | Anti-Echo | Extract style invariants; do not repeat source composition or subject. |
| Simple photo edit | Conservative photo-edit gate | Make only requested changes; protect texture and proportions. |
| Waxy or tiled result | Visual QA and repair | Detect symptom; simplify global detail or repair locally; no causal overclaim. |
| Infographic on shared temperature axis | Data-accurate visual QA | Common scale, computed and verified min/mean/max positions. |
| No renderer available | Tool and renderer contract | Return direction; clearly mark image not rendered. |
| Third-party copyrighted or logo reference | Rights gate + Anti-Echo | Allow general inspiration; do not directly replicate protected marks. |
| Watermark causal diagnosis | Evidence gate | State causation is unverified; give no evasion instructions. |
| Repeated similar outputs | Anti-house-style gate | Change route only when justified by subject, never by random shallow swaps. |

## Review record

For each run, note the fixture, chosen route, decision, any boundary invoked and result status. A human can audit the table directly; the package checker also verifies the expected fixture labels exist.

Release-level limitations: the matrix does not run an image model, use personal or third-party photos, establish a legal determination, or measure renderer performance.
