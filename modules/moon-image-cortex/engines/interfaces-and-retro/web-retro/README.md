# Windows Subthemes · Web Retro

**System:** Moon Image Cortex · **Type:** Windows-era subtheme of [Web Retro Image Gen](../WEB_RETRO_IMAGE_GEN.md) · **Status:** active, conditional · **Parent authority:** [Visual Director](../../../VISUAL_DIRECTOR.md#first-use) · [Windows subtheme index](README.md)

**Renderer:** external and optional. This is a visual-direction contract, not a theme pack, Windows emulator, asset license or rendered screenshot.

## Select one Windows-era subtheme

**Web Retro Image Gen** is the parent engine. Windows-era guidance is grouped into four sibling subthemes, each independently loadable **only when the user's task calls for that operating-system period**.

| Subtheme | Default creative preset | What distinguishes it |
|---|---|---|
| [Windows 98](WINDOWS_98.md) | **Classic gray** | Dense rectangular controls, compact menus, beveled widgets, link-heavy old web |
| [Windows XP](WINDOWS_XP.md) | **Luna Blue** | Cheerful opaque gradients, rounded colored titlebars and green Start |
| [Windows Vista](WINDOWS_VISTA.md) | **Ultimate Black** | Premium black/graphite direction with blue accents and dark-personalized Aero Glass windows |
| [Windows 7](WINDOWS_7.md) | **Aero Blue / neutral** | Revised taskbar, combined/pinned applications, desktop Peek/Snap-era grammar |

**Default rule:** choosing **Windows Vista** automatically selects our **Ultimate Black** *creative preset*, with black packaging-inspired materiality and dark-tinted Aero as relevant to the requested artifact. Users can request another Vista-era tint, Basic appearance or historically faithful screenshot. The preset is an editorial default of this module, **not** a claim that Microsoft shipped a Vista Ultimate-only black operating-system skin.

## Routing steps

1. Classify the overall job using [Web Retro Image Gen](../WEB_RETRO_IMAGE_GEN.md).
2. Identify the Windows subtheme requested: 98, XP, Vista or 7. Do not infer solely from a blue taskbar or transparent frame.
3. Load exactly the matching child. Unspecified OS version stays unspecified; generic late-1990s web imagery does not automatically force Windows 98.
4. Within Windows Vista, apply **Ultimate Black** unless the user gives another colorway, a specific historical source, or an exact screenshot reconstruction requiring different settings.
5. Preserve the distinction between authentic OS screenshot, monitor photograph, promotional packaging and a fictional, newly designed website.
6. Run subtheme-specific QA and source-permission checks. The [Visual Director](../../../VISUAL_DIRECTOR.md#first-use) remains the sole overall authority.

## Cross-version collision tests

| If the image contains… | Likely wrong pairing |
|---|---|
| Luna blue rounded titlebars on a purported Windows 98 desktop | Windows 98 drifted into XP |
| Windows 7 combined/pinned taskbar on an authentic launch-era Vista image | Vista drifted into 7 |
| Vista Sidebar as a mandatory Windows 7 decoration | Optional gadget behavior mistaken for shell identity |
| Modern tiles, centered Start or Mica everywhere | Windows 8–11 features mixed into the older theme |
| CRT scanlines over a native screenshot | Photograph-of-monitor effects copied into a digital image |

No Windows executables, icons, official wallpapers, product packaging artwork or complete operating-system themes are included. A visual direction alone is **not rendered**.

## Evidence

[Microsoft Learn's taskbar reference](https://learn.microsoft.com/en-us/windows/win32/shell/taskbar) identifies important taskbar changes through Windows 7. Vista and 7 child pages cite further original Microsoft technical documentation. The XP page cites an archived design guide. Historical references support **period design choices**, not reproduction rights for protected Microsoft assets.
