# Windows XP · Luna Desktop Subtheme

**System:** Moon Image Cortex · **Type:** Windows-era subtheme of [Web Retro Image Gen](../WEB_RETRO_IMAGE_GEN.md) · **Status:** active, conditional · **Parent authority:** [Visual Director](../../../VISUAL_DIRECTOR.md#first-use) · [Windows subtheme index](README.md)

**Renderer:** external and optional. This is a visual-direction contract, not a theme pack, Windows emulator, asset license or rendered screenshot.

## Component activation

Select **Web Retro Image Gen → Windows XP** for the bright rounded **Luna** desktop idiom (2001 onward), Classic-theme variations when explicitly selected, original XP-era software windows or websites embedded in an era-appropriate browser. The default creative style in this subtheme is **Luna Blue**, not the only color Windows XP ever supported.

## Design system and variants

| Regime | Use | Distinguishing grammar |
|---|---|---|
| **Luna Blue (default)** | Familiar everyday XP desktop, playful software and app window inspiration | Bright blue rounded titlebars, green Start button, warm red close button and relatively friendly high-relief controls |
| **Luna Olive Green** | Muted, earthier legitimate Luna variation | Softer olive/green structural surfaces with compatible widget edges and text contrast |
| **Luna Silver** | Cooler technical/neutral variation | Silver-gray title structures with a consistent underlying XP control anatomy |
| **XP Classic (user-selected)** | Windows 2000-like rectangular control presentation on XP | Square gray system chrome; avoid confusing it with Windows 98's exact app/service state |
| **Original XP-era Web** | Fan/community site, information portal, fictional app in a period browser | Layout density, small graphic navigation, content boxes and link grammar appropriate to the selected year |

### Structural rules

**Start/taskbar:** a recognizable XP-style Start control, taskbar button groups, tray and clock. Keep Quick Launch optional but plausible. Do not import the Windows 7 pinned-application superbar as the default.

**Windows:** rounded top edges in Luna, visible colored titlebar gradient, distinct minimize/maximize/close controls, clear client/titlebar separation. Icons and toolbar affordances can be richer than Windows 98 without becoming Vista semi-realistic glass.

**Typography:** human-readable compact UI labels, moderate hierarchy and simple application form controls. Avoid futuristic thin all-caps fonts or present-day app-design whitespace.

**Surfaces:** use tactile gradients, saturated but bounded colors, shaded inset/raised regions and depth consistent with XP, without blanket transparency, frosted frames or neon-glass panels.

**Nostalgia is not the UI specification.** The well-known grassy wallpaper may be referenced in a user-authorized documentary exercise, but a new design should not require it; choose an original scenic or abstract background when appropriate. Do not imply Microsoft endorsement through recreated product branding.

## Layout decision matrix

| User job | Required decisions |
|---|---|
| Fictional desktop screenshot | Selected Luna palette, taskbar/start layout, plausible app windows and resolution |
| Custom utility window | Client function, XP-style titlebar and control hierarchy, correct menu/dialog density |
| Browser-era website | Page purpose and web grammar separate from XP browser frame |
| Original game launcher | Tactile buttons, compact media list and controls that are usable, not a nonfunctional painted concept |
| Photo of a period PC | Real device screen geometry, ambient lighting and capture artifacts only where physically meaningful |

## Workflow

1. Select Luna Blue unless the user chooses Olive Green, Silver or Classic.
2. Determine whether the result is **an XP operating-system composition**, **an XP-era website**, or **a new site inspired by XP**.
3. Establish taskbar, Start and window chrome only in the mode that needs them.
4. Fix information density, control purpose, gradients, icons and light direction before extra ornament.
5. Keep page/client surfaces clean and readable against colorful frames.
6. Write original content and preserve exact provided text, rather than inventing system errors, brand marks or screenshots.
7. If a renderer is authorized, inspect actual text, titlebar geometry and period consistency.
8. Compare at target size. If the result looks like Windows Vista glass, remove the global blur and recover XP's opaque colored titlebar.

## Synthetic directions

**Luna Blue utility:** “An original Windows XP-style image organizer with rounded blue window chrome, green Start-visible taskbar, warm red close button, inset folder tree and compact thumbnail grid. Distinct readable navigation, no Aero Glass, no Windows 7 superbar, no official vendor mark.”

**Original 2004 web portal:** “A fictional small-town music catalog inside a period browser, fixed-width and dense with compact link lists and rounded blue-bluegray module headers. Keep the browser window and page design independent; no modern floating SaaS cards.”

**Luna Silver developer desk:** “An original 2005 developer environment with Silver variant, compact editor and file-tree panes, meaningful bottom taskbar and plausible controls. The output is a conceptual image, not proof of an installed operating system.”

## QA

Check XP-specific rounded/colored chrome, taskbar and Start layout, palette coherence, readable labels, fidelity to chosen Luna variation, the distinction between browser and web content, and absence of Vista glass or Windows 7 superbar. A dark result is not automatically Windows Vista, and a green button is not enough to certify historical accuracy.

**Output:** period `colorway`, `interface_topology`, `material_and_gradient_rules`, `window_and_browser_roles`, `negative_guidance`, `QA`. A textual direction is **not rendered**.
