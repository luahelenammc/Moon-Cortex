# Windows 7 · Aero Desktop Subtheme

**System:** Moon Image Cortex · **Type:** Windows-era subtheme of [Web Retro Image Gen](../WEB_RETRO_IMAGE_GEN.md) · **Status:** active, conditional · **Parent authority:** [Visual Director](../../../VISUAL_DIRECTOR.md#first-use) · [Windows subtheme index](README.md)

**Renderer:** external and optional. This is a visual-direction contract, not a theme pack, Windows emulator, asset license or rendered screenshot.

## Component activation

Select **Web Retro Image Gen → Windows 7** for the distinctive 2009-era desktop shell, the **Aero** frame language as modified for Windows 7, application windows, original desktop-screen concepts or a derivative web design. Its default direction is a clear, restrained Windows 7 Aero desktop. Alternate Basic or High Contrast appearances are user choices, not automatically interchangeable with Aero.

## Visual grammar and Vista distinction

| Component | Windows 7-era rule | Not to confuse with |
|---|---|---|
| Taskbar | Larger combined application buttons and pinned-program grammar; live thumbnails and taskbar interactions where appropriate | Vista's conventional open-window buttons and distinct optional Quick Launch row |
| Start | Round Start orb and recognizable period Start menu | Windows 8 tiles or centered Windows 11 Start |
| Aero | Translucent/tinted window framing over readable client surfaces; restrained reflection, not all-glass body | Vista Ultimate Black's **creative premium-black preset** or simulated Vista titlebar layout |
| Desktop interaction | Aero Peek, Snap and Shake can belong to Windows 7 when depicted | Assigning them to stock Vista launch-era behavior |
| Show desktop | Right-side taskbar affordance with Aero Peek when relevant | XP-style Quick Launch Show Desktop icon as the default |
| Explorer | Breadcrumb/search shell and period command bar with library-oriented organization as supported by the brief | Windows 8/10 Explorer ribbon or Windows 11 Fluent chrome |
| Widgets | Desktop gadgets when a Windows 7 period scenario explicitly calls for them | Mandatory Vista-sidebar edge panel in every scene |
| Typography/icons | Clear Segoe UI-era style, semi-realistic icon material and functional content hierarchy | Flat mobile monochrome glyph-only aesthetic |

**Windows 7 is not simply “Vista, but more transparent.”** Model taskbar and window behavior, information organization and period-specific features. Glass intensity can be changed without changing the operating-system identity.

## Default and alternative palettes

The **default creative recipe** favors a clean cool-neutral Aero window over a distinct original background, with a legible taskbar and functional light client surfaces. The user may request lighter cyan, subdued charcoal, transparent/tinted frames or Basic mode. Do not impose the Vista Ultimate **Black** preset across Windows 7 merely because they share Aero-era technology.

### Period and content fidelity

A native screenshot may show actual window/tool affordances and user-chosen wallpaper but not camera moiré; a photographed 2009 LCD may have reflections and angle-dependent behavior. Historical application interfaces must use actual evidence for precise OS build numbers, date-stamped patches, specific system dialogs, proprietary logos and product messages.

## Compiler

1. Confirm whether the target is a factual screenshot reconstruction, a fictional period interface, a native site/mockup or a monitor photograph.
2. Fix Windows 7 as the primary visual period. Select Aero/Basic and light/dark glass treatment.
3. Lay out Start and **Windows 7 taskbar** first, including pinned/combined app buttons, thumbnail behavior or Peek only when visually relevant.
4. Define window organization: titlebar, navigation, content pane, search, list/grid areas and action hierarchy.
5. Select a consistent icon/detail level and material response, not blanket macOS-style Aqua or Win11 Mica.
6. Define the original app or website purpose, labels and symbols.
7. If the user wants a responsive living website, make a usable adapted design rather than pretending a desktop screenshot works as a live UI.
8. Inspect for mixed Vista and Windows 7 features, misleading labels, broken contrasts and missing focus or resize behaviors.

## Synthetic direction examples

**Library desktop:** “An original Windows 7-style media library window with Aero-tinted blue-gray border, period taskbar combining app buttons, a visible right-edge Show Desktop area, a compact breadcrumb/search top bar and organized content categories. No Windows 8 ribbon, XP rounded Luna titlebar or Vista mandatory side gadgets.”

**Research app on Aero:** “A fictional 2010 research organizer desktop window, blue-gray translucent frame, clear light list surface, taskbar pinned-application grouping and readable compact labels. Original content and brand; not an official Microsoft screen.”

**Functional site homage:** “A modern semantic information website with subtle Windows 7 Aero-inspired edge softness, shallow gradient and familiar task navigation while preserving correct responsive layout, keyboard focus and readable contrast.”

## QA

Does the taskbar clearly belong to Windows 7 rather than Vista? Are Aero Peek, Snap and Shake absent unless their specific interaction context warrants them? Are application client surfaces readable? Is any simulated glass a material cue rather than a screen-wide opaque/blur filter? Are copyrighted iconography and proprietary UI text properly handled? Has the output been inspected, rather than declared successfully rendered on prompt strength alone?

**Output:** `period_and_appearance`, `taskbar_layout`, `glass_and_client_layers`, `app_semantics`, `medium`, `rights`, `QA_report`. Without an authorized render result, **not rendered**.
