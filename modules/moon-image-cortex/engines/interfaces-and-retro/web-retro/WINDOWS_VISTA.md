# Windows Vista · Web Retro Subtheme

**System:** Moon Image Cortex · **Type:** Windows-era subtheme of [Web Retro Image Gen](../WEB_RETRO_IMAGE_GEN.md) · **Status:** active, conditional · **Scope:** historically informed visual direction, not an operating-system theme, executable shell or official Microsoft product.

**Parent authority:** [Web Retro Image Gen](../WEB_RETRO_IMAGE_GEN.md) under the sole [Visual Director](../../../VISUAL_DIRECTOR.md#first-use) · [Windows subtheme index](README.md) · [Specialist registry](../../../docs/SPECIALIST_ENGINES.md)

**Renderer:** external and optional; this text neither renders pixels nor grants access to copyrighted operating-system assets.

## Component activation

Use this subtheme **after Web Retro Image Gen is selected whenever the user requests Windows Vista**. The **default creative preset is Ultimate Black**, applied according to the artifact class. It is selectable without the user repeating the word “Black.” Use it for:

- Visual design influenced by **Windows Vista Ultimate's black retail-box presentation**.
- A **dark-personalized Windows Vista Aero Glass desktop** or a plausible Vista-era application window.
- A fictional software product, portal or presentation that uses the period's *visual grammar* without copying original Microsoft interface assets.
- Historical comparison of the Vista Ultimate edition's branding, desktop and software-era design language.
- A deliberate hybrid combining Ultimate Black's premium packaging language with a separately identified Vista Aero desktop idiom.

A generic glass UI, Windows XP page, Windows 7 taskbar, Win11 dark mode, Mac OS X Aqua icon or early-2000s fan page does **not** automatically activate Windows Vista. Route those to their own [Windows subthemes](README.md) or other relevant engines.

### Ultimate Black: default creative preset, not an official exclusive OS skin

**Ultimate** was an edition of Windows Vista. Its distinctive predominantly black retail packaging carried a premium hardware/software presentation; Vista's **Windows Aero Glass** desktop was shared across multiple Vista editions on compatible systems. Users could personalize the glass color and transparency. Therefore:

- **Black retail identity** is well supported by contemporary packaging references.
- **Dark-tinted Aero** is a supported *personalization choice* for a period-correct Vista desktop.
- **"Vista Ultimate-only black UI" is not an official default interface and must not be claimed as such.**

**Our default:** when the brief says simply **Windows Vista**, apply the **Ultimate Black** aesthetic direction: dark premium materiality, charcoal/black dominant shell language and restrained blue optical accents, using **dark-personalized Aero** for a desktop or window request. Users may override the colorway and a documented historical source overrides stylistic assumptions in an exact reconstruction. In a direction, explicitly record whether "black" refers to **packaging**, **dark Aero tint**, **wallpaper**, **art direction** or an **original fictional inspired interface**. These are separate controls.

## Visual system: the black packaging

The black retail image is a **corporate premium artifact**. Treat black as mass, restraint and hierarchy rather than a replacement for all colors.

- **Mass:** deep near-black and graphite surfaces with subtle curvature, selective sheen and distinct lit edges.
- **Accents:** controlled azure, electric blue and green-cyan aurora streaks can imply motion and premium technology. These are *descriptive aesthetic families*, not a license to copy the original exact ribbon paths.
- **Typography:** comparatively thin, spacious white/silver modern sans-serif hierarchy, with a strong top-level product name and short subordinate edition information.
- **Optics:** restrained reflective and edge-lit surfaces, large dark negative space, no all-over iridescent liquid glass or rainbow bloom.
- **Object form:** where a 3D software package is requested, an original curved or folded silhouette with believable molded plastic, reflections, printing and dimensional thickness. Avoid an exact official clamshell replica unless the user specifically requests authorized historical documentation.
- **Spatial layout:** fewer strong elements, not a crowded Y2K fan-site or a neon cyberpunk advertisement.

**Suggested derivative palette**, invented for original work rather than sampled official brand tokens:

|---|---|---|

| `graphite` | `#252A33` | Elevated neutral panels |

The color codes are **new working suggestions**, not historical measurements. An authentic UI reconstruction should be constrained by a period screenshot or authoritative theme asset the user may lawfully use.

## Visual system: the Vista Aero desktop

A Vista desktop is a **composited window environment**, not a global glass overlay.

### Era-correct desktop anatomy

| Element | Historical grammar | Frequent anachronism to reject |
|---|---|---|
| Start | Distinct round **Start orb** and Vista Start menu | Windows 8/10 tile-based Start, Windows 11 centered Start |
| Taskbar | Period dark translucent taskbar, conventional open-window taskbar buttons, notification area and optional Quick Launch | Windows 7-style default combined/pinned superbar or Aero Peek |
| Window frames | Translucent/tinted titlebar and edges, coherent minimize/maximize/close placement, readable title | Modern edge-to-edge transparent content or macOS traffic-light controls |
| Client content | Often light neutral surfaces beneath darker glass frames, with functional spacing | Darkening every application panel merely because the frame is black |
| Explorer | Address/breadcrumb navigation, search area, command bar and information/navigation panes as relevant | Ribbon-based Windows 8 Explorer or Windows 11 Command Bar |
| Desktop Sidebar | Optional right-edge gadgets such as clock, weather or feed, sized and integrated plausibly | Windows 11 widgets board or mandatory gadgets everywhere |
| Preview effects | Live taskbar thumbnails and Flip 3D where the depicted workflow calls for them | Aero Snap, Peek or Shake as native Vista-era features |
| Type and icons | Segoe UI-like Vista typography, detailed semi-realistic large pictorial icons, flatter simple toolbar symbols | Universal monochrome outline icon system or pixelated Win95 icons |
| Wallpaper | A Vista-era aurora/abstract field, user-supplied original or period-appropriate image | The assumption that every Ultimate PC must use one fixed green-blue wallpaper |

**Glass is a frame behavior.** Under the Desktop Window Manager, the visual result comes from background compositing through a frosted/tinted surface, not simply applying CSS `opacity` to the whole interface. Preserve dark titlebars while ensuring text and content remain sharp.

### Darkness and transparency are independent

Choose a **glass tint**, **tint saturation**, **transparency intensity**, **wallpaper** and **client-background brightness** as separate parameters. A vivid background can remain visible through a dark frame. Conversely, a matte-black branded window can be original Vista-*inspired* art direction without pretending it is stock Vista.

Do not refer to "High Contrast Black" as an Aero Black setting; it is a distinct accessibility theme that does not mean glass personalization.

### Period anchors and feature availability

- **2007 launch-era Vista:** primary version reference. Aero Glass requires a compatible graphics/display environment and selected appearance mode.
- **2008 SP1-era Vista:** visually similar at a high level; a particular About dialog, system build, patch level or SP1 label must match an evidenced reference if depicted.
- **Ultimate Extras and DreamScene:** historically tied to Ultimate, but an extra's availability/install state cannot be assumed from edition alone; use only if the task is explicitly about that feature. A still image can depict a frame from an animated wallpaper without claiming the animation runs.
- **Media Center:** a valid consumer feature for Ultimate; its presence is not required in every scene.
- **Multilingual UI:** supported in Ultimate, but the screenshot's language must be user-specified or left open. Do not assign English as a national default.

## Translating the style into a new web interface

A **Vista-inspired site** is not the same object as a **literal 2007 operating-system screenshot**. For a working site, preserve contemporary usability and semantic structure while translating a limited set of Vista visual traits.

| Interface layer | Period inspiration | Current usable translation |
|---|---|---|
| Navigation | Shallow glass highlights and dark structured framing | Real accessible navigation with restrained layered gradients |
| Panels | Blue/gray frames with subtle borders and clear title/content distinction | Readable cards on light or muted surfaces, not blanket transparency |
| Controls | Beveled tactile actions, compact Segoe-style text, functional hierarchy | Buttons with visible focus, states and adequate hit areas |
| Decorative glass | Blur and reflected desktop color in titlebars | Browser backdrop blur only where contrast, performance and fallback allow it |
| Iconography | Polished object realism at feature scale | Original custom icon designs; no copied Microsoft system marks |
| Information density | More compact 2007-era arrangements than modern oversized SaaS | Responsive reflow with readable mobile text rather than fixed desktop overflow |

If building a real interface, test keyboard focus, contrast, reduced motion, small screens, and a CSS fallback when background blur is unsupported. A rendered conceptual mockup alone does not establish accessibility or functional behavior.

## Stepwise visual compiler

1. **Reconstruct the user job:** historical educational screenshot, fictional product, new website or original promotional packaging?
2. **Select one of the modes A–E.** Record exactness: documentary reproduction versus stylistic inspiration.
3. **Fix era/platform:** Vista launch-era, SP1-era or intentionally generalized 2007–2009; do not mix Windows 7 shell defaults.
4. **Define the black layer:** retail identity, glass tint, wallpaper or surface color. No automatic all-black scene.
5. **Design the object topology:** desktop shell, Start/taskbar/windows/sidebar for a screenshot; original original-box morphology for a packaging concept; navigation/content for a website.
6. **Choose materials:** simulated frosted glass for frames, light client areas, molded plastic or printed card for packaging, screen-only artifacts for native screenshots.
7. **Establish optical lighting:** local edge reflection, luminous accents and wallpaper interactions; no undirected neon.
8. **Place content and labels:** exact copy from authorized source or concise invented functional labels. Do not invent build numbers, activation status, official edition names or Microsoft endorsements.
9. **Apply originality and licensing checks:** third-party marks and system assets do not become free to reuse because an old product is shown as inspiration.
10. **Compile prompt and negative guidance:** requested scene + period structure + material rules + named exclusions.
11. **Render only if a suitable authorized tool is present**; otherwise deliver a text direction and mark it **not rendered**.
12. **QA against both historical plausibility and the actual job.** For a factual recreation, check against references; for a novel product, evaluate usability and meaningful aesthetics separately.

## Native screenshot, monitor photo and package photograph are different

| Target artifact | Allowed optical behavior |
|---|---|
| **Native desktop capture** | Rectilinear pixels, sharp UI raster, exact window layout within any permitted fictional design; no monitor reflections |
| **Photograph of Vista running on a monitor** | Physical bezel, screen reflection, camera perspective, exposure, focus behavior and potential moiré *only when causally plausible* |
| **Package photograph** | Box/case geometry, paper/plastic sheen, product light and cast shadow; glass window UI appears only if the artwork includes it |
| **Fictional promotional composition** | Clearly authored scene and branding; combined Vista-inspired desktop and packaging materials only by deliberate design |

Do not scatter scratches, CRT scanlines, JPEG noise or film grain onto a clean digital screenshot to make it look old.

## Concrete direction studies

### A. Original premium software box

"Design an **original** 2007-era premium productivity suite retail box influenced by Vista Ultimate's dark packaging language: graphite curved package, large black negative-space field, fine azure aurora reflections and silver contemporary sans-serif hierarchy. Give the fictional product a new brand, title and distinct accent geometry. It must feel like an expensive historical software artifact, **not** an official Vista box clone."

### B. Dark Aero desktop documentation

"Compose a **historically plausible Vista Ultimate desktop** with user-selected dark blue-charcoal Aero glass tint, a circular Start button, a Vista-like taskbar with open-window buttons, one Explorer-style window with breadcrumb navigation and search, optional small clock Sidebar gadget and ordinary bright client content. Keep glass frames translucent but readable. Do not introduce Windows 7 Peek, Snap, pinned superbar or Windows 10 tile Start. If a real system screenshot is required, use verified licensed historical references rather than inventing exact content."

### C. Fictional Vista-era research window

"Create a fictional 2008 desktop research application framed in dark smoky Aero, using a detailed 2007-era large icon, pale list surface, compact left navigation, top search field and conventional window controls. The layout and labels are original and functional; it should feel *of the Vista era* without imitating a Microsoft-owned application pixel-for-pixel."

### D. Responsive modern web homage

"Design an original research portal inspired by premium 2007 Aero: a dark translucent masthead with delicate blue edge reflections, large readable white content surfaces, restrained bevel controls and clear hover/focus states. Keep semantic modern responsive layout and accessibility. This is a Vista-inspired **new website**, not a replica of the operating system."

## QA / failure diagnostics

| Failure | Symptom | Remedy |
|---|---|---|
| Incorrect Ultimate exclusivity | Claims black Aero is the only/default Ultimate UI | Label packaging versus personalized Aero explicitly |
| Glass everywhere | All cards, controls and text are transparent | Confine strong glass to appropriate chrome and preserve client readability |
| Windows 7 drift | Peek, Snap, Shake or superbar appears | Rebuild Vista-era shell, taskbar and window control grammar |
| Windows 10/11 drift | Modern flat tiles, centered taskbar or Mica surfaces | Reintroduce period composition and tactile hierarchy |
| XP/95 drift | Massive gray bevels, bitmap-only icons or old Start strip | Return to Aero DWM-era title frames, high-resolution detailed icons and Segoe-like typography |
| Cyberpunk neon | Blue light beams overwhelm layout and meaning | Restrict luminous accents to packaging or motivated highlights |
| Packaging copied | Almost identical ribbon geometry, exact Windows logo or official SKU text | Create original physical silhouette, line geometry and brand |
| Fake screenshot fidelity | Invented About/System window build number or activation | Mark conceptual recreation; use evidenced values only when actually documented |
| Incorrect device | CRT curves on a native screenshot | Separate digital capture from monitor photography |
| False functionality | A static visual claims animated DreamScene or live UI | Say static depiction; functionality requires an actual implementation |
| Wrong exact copy | Illegible UI labels or fabricated system prose | Reserve copy areas; typeset deterministic checked text |
| Functional contrast failure | Dark labels merge into black glass | Test actual resulting contrast and accessible focus states |

**Acceptance gate:** chosen mode is explicit; black has a defined role; Vista-era shell or packaging facts remain historically coherent; no cross-version UI inventions are presented as authentic; source and logo permissions are respected; intended text is legible; no unperformed render or functional behavior is claimed.
