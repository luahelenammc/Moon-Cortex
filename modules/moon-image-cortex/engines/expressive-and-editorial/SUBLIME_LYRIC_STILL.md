# Sublime Lyric Still

**System:** Moon Image Cortex · **Type:** conditional visual specialist · **Status:** active
**Parent authority:** [Visual Director](../../VISUAL_DIRECTOR.md#first-use) · [Component index](../../docs/COMPONENT_INDEX.md)
**Renderer:** external and optional; this file contains no image generator.

## Component activation

Load this contract **only** when the Visual Director selects Sublime Lyric Still for an actual visual task. If using this file in isolation, first state the task, source permissions, intended output, and tool availability; do not infer that a renderer or identity profile is installed. The Visual Director resolves conflicts and controls handoff. The specialist supplies its own material, composition and QA rules.

## Specialist method

**Trigger:** Vertical still, cover image, or image accompanying user-provided short original text needs atmosphere and scale.

**Visual DNA:** Organize around one dominant natural or spatial force—fog, wind, water, light, cloud, architecture, or shadow. A small subject can establish scale. Negative space provides the pause.

**Composition and material:** Set a vertical reading path, clear horizon or spatial anchor, selective detail and controlled tonal range. Text, if requested, is short, original and subordinate to the image unless the brief says otherwise.

**Must preserve:** User-provided words exactly when required; one atmospheric force; subject scale and placement; requested orientation.

**Avoid:** Copying lyrics or poetry, overfilling the frame, multiple competing phenomena, mandatory monochrome, and decorative script text.

**Direction example:** “Vertical still: a small cyclist waiting beneath a vast viaduct as rain mist moves sideways through warm sodium light; open dark sky above, restrained rust and slate palette, one line of newly written text at lower edge.”

**Input → output:** Orientation, atmospheric force, scale subject, original text and mood → vertical direction sheet and text placement notes.

**QA gate:** At thumbnail size, does one force dominate? Is the subject legible? Are the words exact, original and readable?

**Synthetic case:** “A vertical still for a quiet poem about wind.” Use one tree bending across a broad empty sky; do not supply or imitate a lyric.

## Component return and handoff

Return the smallest useful subset of `direction_sheet`, `prompt_for_renderer`, `edit_instruction`, `QA_report` and source-role constraints. A prompt without an available authorized renderer must say **not rendered**. The Visual Director remains the only general operational entry. Examples above are synthetic instructions, not validated output samples.
