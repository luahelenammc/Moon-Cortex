# Chromatic Dream Logic

**System:** Moon Image Cortex · **Type:** conditional visual specialist · **Status:** active
**Parent authority:** [Visual Director](../../VISUAL_DIRECTOR.md#first-use) · [Component index](../../docs/COMPONENT_INDEX.md)
**Renderer:** external and optional; this file contains no image generator.

## Component activation

Load this contract **only** when the Visual Director selects Chromatic Dream Logic for an actual visual task. If using this file in isolation, first state the task, source permissions, intended output, and tool availability; do not infer that a renderer or identity profile is installed. The Visual Director resolves conflicts and controls handoff. The specialist supplies its own material, composition and QA rules.

## Specialist method

**Trigger:** The user wants a coherent visual language organized by color, material, sharpness and spatial logic without specifying a fixed subject theme.

**Visual DNA:** Treat it as a thematic-neutral meta-style compiler with one visual thesis. Coordinate a controlled palette of two to four colors, light, surface, edge treatment, depth and selective focus. It is a historical prompt grammar studied in the Midjourney V3 era, not an image model, API, weights, or claim of equivalent behavior.

**Composition and material:** Reserve crispness for the focal element; support it with atmospheric softness, tactile contrast, and deliberate negative space. Themes and motifs are selected from the brief.

**Must preserve:** User’s chosen subject and emotional intent; color structure should not replace meaning.

**Avoid:** Automatic moons, gothic symbols, cosmic space, ornate architecture, monochrome, or any predetermined theme.

**Direction example:** “A red ceramic seedling tray on a bright workbench; restrained coral, leaf green and warm ivory; crisp glazed rim, soft greenhouse background, angled sun, generous work surface, no mystical symbols.”

**Input → output:** Subject, mood, palette constraints and material cues → one visual thesis and theme-neutral direction.

**QA gate:** Check that palette and surface support the subject, focal hierarchy reads, and no inherited motif has displaced the brief.

**Synthetic case:** “Make a non-gothic chromatic image about a ceramic mug after rain.” Keep the theme ordinary and let water, glaze, window light and color carry the visual logic.

## Component return and handoff

Return the smallest useful subset of `direction_sheet`, `prompt_for_renderer`, `edit_instruction`, `QA_report` and source-role constraints. A prompt without an available authorized renderer must say **not rendered**. The Visual Director remains the only general operational entry. Examples above are synthetic instructions, not validated output samples.
