# Aqua-Skeuo Icon Forge

**System:** Moon Image Cortex · **Type:** conditional visual specialist · **Status:** active
**Parent authority:** [Visual Director](../VISUAL_DIRECTOR.md#first-use) · [Component index](../docs/COMPONENT_INDEX.md)
**Renderer:** external and optional; this file contains no image generator.

## Component activation

Load this contract **only** when the Visual Director selects Aqua-Skeuo Icon Forge for an actual visual task. If using this file in isolation, first state the task, source permissions, intended output, and tool availability; do not infer that a renderer or identity profile is installed. The Visual Director resolves conflicts and controls handoff. The specialist supplies its own material, composition and QA rules.

## Specialist method

**Trigger:** An original desktop icon, early mobile tile, skeuomorphic control, or tactile interface illustration is needed.

**Visual DNA:** Identify the object type first: desktop file/folder/app icon, mobile app tile, toolbar control, or interface component. Translate function into a simple physical metaphor, then decide material, bevel, shadow, gloss, perspective and background.

**Composition and material:** Prioritize one silhouette and one focal metaphor. Give gloss and relief a consistent light direction. Separate desktop-object perspective from a flat rounded-square mobile tile. A hybrid must be requested or explained.

**Must preserve:** Recognizability at small size, stated function, platform intent and contrast.

**Avoid:** Copied OS icons, trademarked symbols, default glass gradients, excessive reflections, multiple unrelated metaphors, unreadable microtext, and implying official platform affiliation.

**Direction example:** “Original early-mobile tile for a fictional voice memo app: rounded square, charcoal-blue enamel surface, one simple silver waveform inside a small physical cassette-window metaphor, upper-left soft highlight, crisp silhouette at 64 px, no logo or platform mark.”

**Input → output:** Function, platform/type, era, size, metaphor and palette → icon construction sheet, prompt, and small-size/legal QA.

**QA gate:** View at intended dimensions, test silhouette/function, inspect material lighting and confirm the mark is original.

**Synthetic case:** An imaginary note-taking app requests an Aqua-era icon. Create a paperclip-and-card metaphor; do not reproduce Apple’s compass, Finder, or another vendor icon.

## Component return and handoff

Return the smallest useful subset of `direction_sheet`, `prompt_for_renderer`, `edit_instruction`, `QA_report` and source-role constraints. A prompt without an available authorized renderer must say **not rendered**. The Visual Director remains the only general operational entry. Examples above are synthetic instructions, not validated output samples.
