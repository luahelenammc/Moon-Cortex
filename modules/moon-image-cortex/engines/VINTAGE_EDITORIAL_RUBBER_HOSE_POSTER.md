# Vintage Editorial Rubber Hose Poster

**System:** Moon Image Cortex · **Type:** conditional visual specialist · **Status:** active
**Parent authority:** [Visual Director](../VISUAL_DIRECTOR.md#first-use) · [Component index](../docs/COMPONENT_INDEX.md)
**Renderer:** external and optional; this file contains no image generator.

## Component activation

Load this contract **only** when the Visual Director selects Vintage Editorial Rubber Hose Poster for an actual visual task. If using this file in isolation, first state the task, source permissions, intended output, and tool availability; do not infer that a renderer or identity profile is installed. The Visual Director resolves conflicts and controls handoff. The specialist supplies its own material, composition and QA rules.

## Specialist method

**Trigger:** A serious editorial, educational or advocacy claim benefits from a simplified original character and a memorable visual metaphor.

**Visual DNA:** Reduce the claim to one conflict, embody it in one visible mechanism, and turn that mechanism into a clear image. A fictional mascot can carry the argument without resembling a known artist’s character.

**Composition and material:** Use large editorial typography, restrained palette, aged paper or ink only when useful, one focal action and clear reading distance. Optional political-cartoon submode: aim for a clear thesis at about two seconds and a visible turn by ten seconds, with less text. This is a reading-time design heuristic, not a measured guarantee; avoid trivializing victims.

**Must preserve:** The argument, dignity of affected people, legibility, and seriousness proportional to the subject.

**Avoid:** Trivializing victims, using real people as caricature without authorization, mimicking a living illustrator’s signature style, false slogans, ornate clutter, childish cuteness, or gloss that weakens the claim.

**Direction example:** “Original civic poster: one oversized rubber stamp marked ‘DELAY’ pins a fictional service doorway shut while a small queue waits; warm paper, charcoal and brick red, large neutral sans headline supplied by the user, no copied mascot or artist signature.”

**Input → output:** Claim, audience, single conflict, ethical constraint and text → visual metaphor, poster hierarchy, original prompt and seriousness QA.

**QA gate:** Can the thesis be read quickly? Is the turning point visible? Are affected people treated with dignity? Is the character original?

**Synthetic case:** A fictional poster about a delayed public service. Make the obstructing mechanism visible and preserve the people’s dignity; do not turn hardship into a joke.

## Component return and handoff

Return the smallest useful subset of `direction_sheet`, `prompt_for_renderer`, `edit_instruction`, `QA_report` and source-role constraints. A prompt without an available authorized renderer must say **not rendered**. The Visual Director remains the only general operational entry. Examples above are synthetic instructions, not validated output samples.
