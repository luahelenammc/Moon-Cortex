# Geographic Camera Contexts

These **optional location lenses** sit below [Contextual Nostalgic Camera](../CONTEXTUAL_NOSTALGIC_CAMERA.md) and can accompany [Vernacular Snapshot Realism](../VERNACULAR_SNAPSHOT_REALISM.md). ## Choose responsibly

1. Only activate an adapter if the user explicitly names the scene place or it is clearly verified by a relevant source. A person's nationality or ethnicity never determines where an image was taken.
2. Prefer specificity **inside the chosen place**, not broad national symbols. Document country/region/city and time independently.
3. Confirm media and capture process separately from geographic context; a camera's hardware does not possess a nationality.
4. A scene can combine multiple geographic influences because migration, travel and mixed households exist. Never make one person or one place stand for a nation.
5. If unspecified, keep geographic context **null/unknown** and use the parent camera engine without an adapter.
6. Avoid claims of representativeness; these are synthetic context-research scaffolds, not validated region datasets or licensed photo packs.

See [custom context](CUSTOM_CONTEXT.md) to apply this method to **any** place.
