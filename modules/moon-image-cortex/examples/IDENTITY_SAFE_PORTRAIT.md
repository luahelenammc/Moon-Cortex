# Synthetic example: identity-safe portrait

**Scenario:** A fictional consenting subject supplies one portrait and asks for a new professional headshot in a different setting.

**Route:** Human Canon Forge + a restrained photographic direction.

**Evidence lanes:** Observed from the supplied reference: short dark curls, round glasses, face turned slightly left. Subject-described: “keep my usual expression; no makeup change.” Unknown: height, exact age, background, ethnicity, personality.

**Direction:** Preserve face shape, skin texture, curl pattern, glasses, expression and natural proportions. Change only background, crop, wardrobe color if approved, and soft window lighting. Create one local identity profile only if the subject asks; list its consent scope and deletion condition.

**QA:** Verify which identity anchors remain visible and whether the background changed as requested. Do not infer sensitive traits or claim exact likeness from text. If no renderer is used, return direction only.
