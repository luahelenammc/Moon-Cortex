# Synthetic example: historical web and tactile icon

**Input A:** “Create a fictional 2003 neighborhood film-club page with monthly screenings.”

**Route:** Web Retro Image Gen.

**Direction:** Fixed-width early-web page, compact links and dense information, restrained blue-gray accents, original film-club name and mark, low-resolution banner, era-plausible browser frame only if a screenshot is requested. No real platform brand or copied layout.

**QA:** Readable title and dates, no modern responsive SaaS cards, correct distinction between browser screenshot and photographed monitor.

**Input B:** “Design an icon for an imaginary voice memo app in an early-2010s glass-and-metal interface.”

**Route:** Aqua-Skeuo Icon Forge.

**Direction:** One cassette-window metaphor, square tile, smoked glass over slate metal, coherent upper-left light, recognizable at 64 px, original mark.

**QA:** Silhouette remains clear when small; the material reads without copied OS icons or vendor logo. These are directions only; no rendered image is included.


**Input C:** “Show an original 2008-era dark Vista Ultimate-inspired productivity screen.”  
**Route:** Web Retro Image Gen → [Windows Vista](../engines/interfaces-and-retro/web-retro/WINDOWS_VISTA.md) (Ultimate Black default preset).  
**Direction:** A dark-tinted Aero frame, Vista-style window controls, a breadcrumb/search top region and *light, readable* content panes. Keep the black Ultimate retail-box identity separate from user-configurable glass tint. No Windows 7 pinned superbar, Aero Peek or official brand reproduction.  
**QA:** Distinguish desktop screenshot from photographed monitor, verify era-correct shell and do not claim it is a real installed operating system.

**Input D:** “Create a fictional Windows 98 computer-archive utility.”  
**Route:** Web Retro Image Gen → [Windows 98](../engines/interfaces-and-retro/web-retro/WINDOWS_98.md).  
**Direction:** Compact rectangular Classic gray dialogs with inset file panels, discrete taskbar buttons and crisp native screenshot geometry.  
**QA:** No XP Luna chrome, Vista glass or modern Windows taskbar.

**Input E:** “Design a nostalgic Windows XP-era media organizer.”  
**Route:** Web Retro Image Gen → [Windows XP](../engines/interfaces-and-retro/web-retro/WINDOWS_XP.md).  
**Direction:** Luna Blue titlebars, controlled rich gradients, compact folder list and readable buttons, fictional software name and original icons.  
**QA:** Blue/green XP geometry, no Vista Aero transparency.

**Input F:** “Design a fictional research organizer as a Windows 7 desktop screenshot.”  
**Route:** Web Retro Image Gen → [Windows 7](../engines/interfaces-and-retro/web-retro/WINDOWS_7.md).  
**Direction:** Subtle Aero blue frame, Windows 7 taskbar with pinned/combined applications, original app content and readable client panels.  
**QA:** No XP Luna, Vista taskbar layout or Windows 8 ribbon.
