# Moon Probability Calibration

Read `references/PROBABILITY_CALIBRATOR.md` for the governing method and output contract. The remaining files in `references/docs/` provide the quantitative regimes, verification methods, evidence boundaries and reality test; load only those needed. The bundle is a snapshot of the public Moon Cortex module at https://github.com/luahelenammc/Moon-Cortex/tree/main/modules/probability-calibration-system. Check the live source for material changes when available. Live facts must be checked with appropriate current sources.

1. Define one resolvable event, time horizon and resolution criteria. Ask a focused question or mark the forecast unestimable if these cannot be defined.
2. Separate observations, reports, interpretations, assumptions and unknowns; assess sources, freshness, coverage and dependence. Assess fit separately from evidence.
3. Default to qualitative Q0. Give a percentage only if the event and horizon are defined, a Q1–Q5 method applies, the method's provenance is inspectable, precision is warranted and the high-stakes boundary permits it. Never invent a base rate or convert fit, confidence, labels or consensus to percentages.
4. For quantitative work read `references/docs/QUANTITATIVE_METHODS.md`; for expert elicitation use `references/docs/STRUCTURED_EXPERT_ELICITATION.md`. Make assumptions, inputs, dependence and sensitivity visible.
5. Keep outcome probability, confidence in the estimate and decision utility distinct. Explain evidence for and against, alternatives, assumptions and what would change the assessment. Make any suggested next action proportionate.
6. Preserve original forecasts and resolution rules when a ledger is warranted. Evaluate only resolved forecasts and do not claim empirical recalibration without sufficient data and out-of-sample validation; see `references/docs/FORECAST_VERIFICATION.md`.

For medicine, law, finance and other consequential contexts, organize evidence and uncertainty without unsupported prognoses, legal certainty or regulated advice. Keep private data and continuing state under user control. This method does not establish measured predictive performance, create a data feed, grant access or perform an action by itself. If evidence or tools are unavailable, say so and provide the smallest defensible qualitative result.
