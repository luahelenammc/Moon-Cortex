# Moon Cortex

Moon Cortex is a public pre-release lineage for domain modules that help AI systems generate situated, user-owned capabilities.

The repository is intentionally small at this stage. The first public module, Finance Bootstrap Seed, is being introduced as the initial test of a generative module inside Moon Cortex.

Moon Cortex is distinct from [Moon Source](https://github.com/luahelenammc/Moon-Source):

- Moon Cortex defines domain-module identity and functional lineage.
- Moon Source provides public context-architecture and installation methods when a module uses them.
- The resulting local system belongs operationally to the user.

The repository is under public pre-release development. Its future module taxonomy and complete architecture are not finalized here.
