# Moon Cortex

Moon Cortex is a public pre-release lineage for domain modules that help AI systems generate situated, user-owned capabilities.

The repository is intentionally small at this stage. **Moon Cortex · Financial Living System** is the first available module and the first test of a generative domain system inside Moon Cortex. It is instantiated through an **Adaptive Finance Bootstrap**, not delivered as a fixed finance template.

## Pre-inauguration milestone

On **2026-09-01**, Moon Cortex entered public **pre-inauguration** through its first usable module: **Financial Living System 0.1.0-pre.2**.

This is intentionally narrower than a full Moon Cortex launch. It makes one bounded Cortex module publicly usable and inspectable while the broader Cortex taxonomy, module family and long-term architecture remain under development.

## Start with the module

Open or provide [`modules/finance-bootstrap/FINANCE_BOOTSTRAP_SEED.md`](modules/finance-bootstrap/FINANCE_BOOTSTRAP_SEED.md) to an AI as operative context. The filename is retained for path stability; semantically, this file is the canonical **Adaptive Finance Bootstrap** for the Financial Living System.

The bootstrap is **self-activating by default**: the AI should begin adaptive setup automatically unless the user explicitly asks only to read, review or analyze it without execution. The user does not need to know a command phrase or Moon Source vocabulary before receiving value.

The Adaptive Finance Bootstrap maps the user's financial reality before selecting capabilities or a local form. It can run in standalone mode and can use the current public Moon Source repository as an installation/context-governance bridge.

```text
Financial Living System
        ↓ instantiated through
Adaptive Finance Bootstrap
        ↓
user-local living financial system
```

## Moon Cortex and Moon Source

Moon Cortex is distinct from [Moon Source](https://github.com/luahelenammc/Moon-Source):

- Moon Cortex defines domain-module identity and functional lineage.
- The Financial Living System is the finance module/product identity.
- The Adaptive Finance Bootstrap discovers the user's field and configures the local system.
- Moon Source provides public context-architecture and installation methods when deliberately consulted.
- The resulting local system belongs operationally to the user.

The short boundary is:

> **Cortex by identity. Bootstrap by instantiation. Moon Source by installation governance. The user by final sovereignty.**

## Pre-release boundary

This repository is under public pre-release development. The complete future Cortex taxonomy and architecture are not finalized here. Finance is a domain proof, not a decree that every future module must use a bootstrap mechanism.

The public repository contains generalized mechanisms and fictional examples. It does not contain private Finanças Moon data, private Moon Source material, bank connectors, autonomous transactions or a user interface.
